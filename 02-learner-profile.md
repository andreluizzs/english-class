## Typical Brazilian mistakes to watch (prioritize if they appear)
| Portuguese influence | Wrong | Right |
|---|---|---|
| "Ter X anos" | I have 40 years | I'm 40 (years old) |
| Missing subject | Is important to... | **It** is important to... |
| "Fazer uma pergunta" | make a question | **ask** a question |
| "Discutir sobre" | discuss about the scope | discuss the scope |
| "Explicar para mim" | explain me | explain **to** me |
| "Depender de" | depends of | depends **on** |
| People = plural | people is | people **are** |
| Present perfect | I work here since 2014 | I**'ve worked** here since 2014 |
| Past vs perfect | Did you ever use SAP? | **Have** you ever used SAP? |
| False friend | Actually (= atualmente) | Actually = na verdade · currently = atualmente |
| False friend | pretend (= pretender) | **intend / plan** to |
| Uncountable | informations, softwares, feedbacks | information, software, feedback |
| Prepositions | in Monday / on 2026 | **on** Monday / **in** 2026 |
| "Assistir" | assist a game | **watch** a game |
| Word order | I like very much football | I really like football |
